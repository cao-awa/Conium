# Data-driven
## Item
1. Add compostable component and template. (’minecraft:compostable‘, 'compostable)
2. Add display name component and template. ('minecraft:display_name', 'display_name')
3. Add fire resistance component and template. ('minecraft:fire_resistant',	'fire_resistant')
4. Add enchantable component and template. ('minecraft:enchantable', 'enchantable')
5. Add cooldown component and template. ('minecraft:cooldown', 'cooldown')

## Block
1. Add friction component and template. ('minecraft:friction', 'friction')
2. Add replaceable component and template. ('minecraft:replaceable', 'replaceable')

## Entity
1. Add fire immune component and template. ('minecraft:fire_immune', 'fire_immune')
2. Add health component and template. ('minecraft:health', 'health')
3. Add movement component and template. ('minecraft:movement', 'movement' / 'movement_speed')
4. Add knockback resistance component and template. ('minecraft:knockback_resistance', 'knockback_resistance')
